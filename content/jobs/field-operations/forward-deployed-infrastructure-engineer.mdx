# Forward Deployed Infrastructure Engineer

### The Mission

Software means nothing without infrastructure to run it on. Chemist3's Forward Deployed Infrastructure Engineers are the operators who walk into client data centers, edge sites, and air-gapped environments and make hardware talk to software — reliably, securely, and under constraints that would paralyze a cloud-native engineer who has never touched a rack.

This role exists because our most critical clients operate in environments where "just spin up a VM" is not an option. You will install bare-metal servers, configure on-premise networking stacks, provision edge devices, set up air-gapped cloud environments, and build the physical and logical foundation that Chemist3 software runs on. You are the last mile between our platform and operational reality — and that last mile is often the hardest.

If your idea of infrastructure is clicking buttons in a cloud console, this is not your role. If you have rack-and-stack scars, can subnet a network in your head, and have debugged boot failures at 2 AM in a facility with no internet access, we want to talk to you.

### Core Responsibilities

- Execute bare-metal server installations, BIOS/firmware configuration, and hardware validation at client sites — including environments with restricted physical access and security clearance requirements.
- Design and implement on-premise networking topologies: VLANs, firewalls, VPNs, DNS, DHCP, and routing configurations tailored to client security postures.
- Provision and configure edge computing devices, IoT gateways, and remote sensor infrastructure for data collection and local processing workloads.
- Build and maintain air-gapped deployment environments — including offline package repositories, image registries, and update mechanisms that function without internet connectivity.
- Integrate client hardware ecosystems with Chemist3 software platforms, ensuring compatibility across heterogeneous operating systems, hypervisors, and storage backends.
- Develop and execute infrastructure acceptance testing procedures, burn-in protocols, and failover validation before handing systems to operational teams.
- Create detailed site survey reports, network diagrams, and rack elevation documentation that enable remote teams to support deployed infrastructure.
- Maintain secure chain-of-custody for hardware assets, encryption keys, and access credentials throughout deployment lifecycles.

### What We Look For

**Technical / Domain Competencies:**
- Hands-on experience with server hardware: Dell PowerEdge, HPE ProLiant, Supermicro, or equivalent — including RAID configuration, iDRAC/iLO management, and firmware updates.
- Strong Linux systems administration (RHEL, Ubuntu Server, CentOS) with deep knowledge of systemd, networking stack, storage management (LVM, ZFS), and kernel tuning.
- Proficiency in network engineering: TCP/IP, routing protocols, firewall rules (iptables/nftables, pfSense), 802.1Q VLANs, and WireGuard/IPsec VPN tunnels.
- Experience with virtualization platforms (KVM/QEMU, VMware ESXi, Proxmox) and container runtimes in on-premise contexts.
- Familiarity with configuration management tools (Ansible, Salt, Puppet) and infrastructure-as-code for reproducible deployments.
- Prior work in defense, intelligence, critical infrastructure, or industrial environments is strongly preferred.

**Mindset & Attributes:**
- Comfortable working in physically demanding and access-restricted environments — server rooms, mobile command posts, remote facilities.
- Methodical troubleshooting discipline — you can isolate a failure across hardware, firmware, OS, and application layers systematically.
- Self-directed and operationally independent — you can execute a full site deployment with minimal remote support.
- Security-conscious by default — you treat every credential, every port, and every physical access point as a potential attack surface.
- Willingness to travel extensively, including short-notice deployments.

### Operating Principles

- **Field-First Engineering:** Infrastructure that cannot survive the physical realities of client environments is not infrastructure — it is a lab experiment.
- **Zero Layering:** You are the engineer on site. There is no escalation path that does not start and end with you.
- **Outcomes Over Deliverables:** A rack installed on time and passing acceptance tests matters more than a perfect architecture diagram that never ships.
