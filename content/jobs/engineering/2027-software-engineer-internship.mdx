# 2027 Software Engineer Internship

### The Mission

Chemist3 Labs engineers foundational software systems that operate under strict reliability, correctness, and performance demands. As a Software Engineer Intern for 2027, you will join our core engineering team to build scalable services, algorithm pipelines, and high-throughput data infrastructure.

You will not be sidelined with superficial tasks. You will contribute production code to our core architecture, design robust APIs, optimize critical computational paths, and collaborate directly with senior systems architects. We look for individuals who are energized by hard engineering problems, rigorous peer review, and deep technical learning.

### Core Responsibilities

- Design, implement, and benchmark backend components, microservices, and internal libraries.
- Write clean, maintainable, and type-safe code in TypeScript, Go, Rust, or Python.
- Develop unit tests, integration test suites, and regression benchmarks to verify subsystem behavior under load.
- Optimize query performance and schema design for relational and key-value storage engines (PostgreSQL, Redis).
- Build automated CI/CD pipeline steps and deployment configurations to support continuous delivery.
- Investigate and troubleshoot edge cases, concurrency hazards, and performance bottlenecks alongside core engineering mentors.
- Participate in technical design sessions and contribute to internal architectural decision records (ADRs).

### What We Look For

**Technical / Domain Competencies:**
- Enrolled in an undergraduate, master's, or doctoral program in Computer Science, Software Engineering, or a related quantitative field.
- Solid understanding of data structures, algorithms, asymptotic complexity, and systems architecture.
- Proficiency in at least one modern programming language: TypeScript/JavaScript, Go, Rust, C++, or Python.
- Experience with web protocols (HTTP/REST, WebSockets, gRPC) and asynchronous programming patterns.
- Familiarity with database systems (relational SQL databases and basic query analysis).
- Comfort working in Unix/Linux command-line environments and standard developer workflows (Git, code review, linting).

**Mindset & Attributes:**
- Intellectual rigor: you question assumptions and verify system behavior empirically.
- High standards of craftsmanship: you care deeply about code readability, maintainability, and clean abstractions.
- Effective communication: you can articulate trade-offs between different technical approaches.
- Team orientation: you take pride in collective output and learn enthusiastically from experienced engineers.

### Operating Principles

- **Correctness First:** We prioritize verifiable correctness and predictable performance over hasty shortcuts.
- **Radical Candor in Review:** Code reviews are collaborative, thorough, and focused on shared excellence.
- **Deep Technical Curiosity:** Explore all layers of the stack to understand how code interacts with the underlying runtime and hardware.
