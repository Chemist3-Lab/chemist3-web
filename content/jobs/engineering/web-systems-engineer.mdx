# Web Systems Engineer

### The Mission

Chemist3 Labs' web surfaces are not marketing pages — they are operational interfaces. The public site, client demonstration portals, developer documentation platforms, and internal tooling dashboards are the front door to everything we build. The Web Systems Engineer owns the full stack of Chemist3's digital presence, from rendering performance to deployment infrastructure to the interactive systems that demonstrate our platform capabilities to prospective clients and partners.

This role sits at the intersection of frontend engineering and systems thinking. You will build performant, accessible, and maintainable web applications using modern frameworks, but you will also own the build pipelines, hosting infrastructure, CDN configuration, and deployment automation that keep those applications running. You are not a "frontend developer" who hands off deployment to someone else. You own the entire lifecycle — from component architecture through CI/CD to production monitoring.

The bar is high because these surfaces represent Chemist3 to the outside world. A slow page load, a broken demo portal, or documentation that cannot be found costs us credibility with the exact clients and engineers we are trying to reach. If you care deeply about web performance, developer experience, and building systems that are as well-engineered under the hood as they appear on screen, this role will challenge and reward you.

### Core Responsibilities

- Architect, build, and maintain Chemist3's public web presence — marketing site, blog, careers pages, and company documentation — using modern frameworks (Next.js, Astro, or equivalent) with a focus on performance, SEO, and accessibility.
- Develop and operate client-facing demonstration portals that showcase Chemist3 platform capabilities through interactive, data-driven interfaces.
- Build and maintain developer documentation surfaces — API references, integration guides, tutorials, and SDK documentation — with emphasis on searchability, versioning, and developer experience.
- Own the full deployment pipeline for web properties: build systems, static site generation, CDN configuration, edge caching strategies, and preview/staging environments.
- Implement design systems and component libraries that enforce visual consistency and accelerate development across multiple web surfaces.
- Integrate web surfaces with backend services, authentication systems, and analytics platforms — handling API consumption, state management, and real-time data rendering.
- Monitor web performance metrics (Core Web Vitals, Lighthouse scores, error rates) and systematically improve load times, interactivity, and reliability.
- Collaborate with Interface & Experience Designers to translate design specifications into production-quality implementations that respect both visual fidelity and engineering constraints.

### What We Look For

**Technical / Domain Competencies:**
- Expert-level TypeScript and modern React (hooks, server components, streaming SSR) with production experience in Next.js, Remix, or Astro.
- Deep understanding of web performance optimization: code splitting, lazy loading, image optimization, critical rendering path, and caching strategies.
- Proficiency with CSS architecture at scale — CSS Modules, Tailwind CSS, or CSS-in-JS — with a focus on maintainability and design system compliance.
- Experience with headless CMS platforms (Contentlayer, Sanity, Contentful) or MDX-based content systems for documentation and editorial workflows.
- Strong DevOps skills for web: Vercel, Cloudflare Pages, or self-hosted deployment pipelines with CI/CD automation (GitHub Actions, GitLab CI).
- Familiarity with web accessibility standards (WCAG 2.1+), semantic HTML, and assistive technology testing.
- Working knowledge of backend-for-frontend patterns, API design, and authentication/authorization flows (JWT, session management, OAuth).

**Mindset & Attributes:**
- Ownership mentality across the full stack — you do not consider your job done when the component renders. You own it through deployment, monitoring, and incident response.
- Obsessive attention to detail in both visual implementation and code quality — pixel precision and clean abstractions matter equally.
- Performance-oriented engineering mindset — you measure, profile, and optimize rather than guessing.
- Comfort working independently on web infrastructure decisions while collaborating closely with designers and content stakeholders.
- Genuine interest in developer experience — you care about how other engineers interact with the systems you build.

### Operating Principles

- **Outcomes Over Deliverables:** A documentation site that developers actually use and find valuable is success. A beautifully designed site with poor search and broken links is failure.
- **Zero Layering:** You own the web surface end-to-end. There is no separate "DevOps team" for web deployment or "content team" for documentation architecture. You are the team.
- **Field-First Engineering:** Every web surface you build serves a real operational purpose — client acquisition, developer enablement, or platform demonstration. Vanity projects do not ship.
