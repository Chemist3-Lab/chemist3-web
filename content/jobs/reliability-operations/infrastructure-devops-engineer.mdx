# Infrastructure & DevOps Engineer

### The Mission

Every line of code Chemist3 Labs ships depends on infrastructure that is automated, reproducible, and resilient. The Infrastructure & DevOps Engineer builds and maintains the machinery that turns source code into running production systems — CI/CD pipelines, container orchestration, cloud resource management, build systems, and deployment automation that operate with the reliability and velocity a defense-tech company demands.

This role is the backbone of Chemist3's engineering operations. You will own the systems that package, test, deploy, and monitor every service we ship — across cloud environments, on-premise installations, and air-gapped deployments. When a Forward Deployed engineer needs a reproducible build artifact at a client site, your pipeline produced it. When a production service needs to scale under load, your orchestration handles it. When a developer pushes code, your CI catches the breakage before it reaches any environment that matters.

If your DevOps experience is limited to writing YAML files that someone else designed, this role will stretch you. If you have built deployment pipelines from scratch, debugged container networking at the kernel level, and automated infrastructure provisioning across multiple cloud providers, you are operating at the level we need.

### Core Responsibilities

- Design, build, and maintain CI/CD pipelines that compile, test, scan, package, and deploy services across multiple target environments — cloud, on-premise, and air-gapped — with full auditability and rollback capability.
- Manage container orchestration infrastructure (Kubernetes, Nomad, or Docker Swarm): cluster provisioning, namespace management, resource quotas, network policies, and storage configuration.
- Provision and manage cloud infrastructure (AWS, GCP, Azure) using infrastructure-as-code (Terraform, Pulumi, CloudFormation) with state management, drift detection, and cost optimization.
- Build reproducible build systems: hermetic builds, dependency pinning, multi-architecture image compilation, and artifact signing/verification for supply chain security.
- Implement secrets management, certificate rotation, and credential distribution systems that operate securely across development, staging, and production environments.
- Develop and maintain developer tooling: local development environments, pre-commit hooks, automated code formatting, dependency update bots, and developer documentation for infrastructure workflows.
- Build deployment strategies: blue-green deployments, canary releases, feature flags, and progressive rollout systems that minimize blast radius for production changes.
- Monitor infrastructure health: resource utilization, cost trends, deployment frequency, lead time, change failure rate, and recovery time — using these metrics to drive continuous improvement.

### What We Look For

**Technical / Domain Competencies:**
- Expert-level Kubernetes: cluster administration, Helm charts, custom operators, network policies (Calico, Cilium), ingress controllers, and persistent storage management.
- Strong infrastructure-as-code proficiency: Terraform (modules, providers, state management) or Pulumi with production experience across at least one major cloud provider.
- Deep CI/CD experience: GitHub Actions, GitLab CI, Jenkins, or ArgoCD — including pipeline optimization, parallelization, caching strategies, and security scanning integration.
- Linux systems proficiency: process management, filesystem hierarchy, networking stack, cgroups/namespaces, and performance diagnostics.
- Container expertise: Dockerfile optimization, multi-stage builds, image scanning, registry management, and runtime security.
- Scripting and automation: Python, Bash, Go, or equivalent — for glue code, infrastructure automation, and custom tooling.
- Experience with GitOps workflows, artifact management (Artifactory, Harbor, Nexus), and supply chain security (Sigstore, SBOM generation).

**Mindset & Attributes:**
- Automation-first mentality — if you do something twice manually, the third time should be automated.
- Deep operational empathy — you understand that developer productivity is directly impacted by the quality of the infrastructure and tooling you provide.
- Security consciousness integrated into every infrastructure decision — you do not treat security as a separate concern from availability and performance.
- Systematic troubleshooting across the full stack: network, DNS, container runtime, orchestrator, application, and cloud provider layers.
- Comfort operating in environments with strict compliance requirements, air-gap constraints, and limited internet access.

### Operating Principles

- **Outcomes Over Deliverables:** A pipeline that reliably delivers tested, signed artifacts to any target environment in under 15 minutes is success. A pipeline that is architecturally elegant but flaky is failure.
- **Zero Layering:** Infrastructure engineers work directly with the developers using the pipelines and the operators deploying the artifacts. There is no ITSM ticket queue between you and the people you serve.
- **Extreme Ownership:** If a deployment fails because of a pipeline bug, an expired certificate, or a misconfigured resource quota, you own the incident — regardless of who triggered the deployment.
